# SS TOKYO DRESSES

A mobile-first static shopping website for **SS TOKYO DRESSES**, featuring ethnic blouse collections for saree looks.

## What is included

- Home, shop, product, cart, about and contact pages
- Masoba, Mumtaz, Mumtaz D2 and Queen blouse catalogues
- Colour choices, size guides, ratings, sale prices and product galleries
- A working shopping bag saved in the browser
- Delivery calculation: free delivery above ₹1,799 and ₹60 below it
- Checkout form with UPI and Cash on Delivery information

## How to preview it

1. Open the `index.html` file in any web browser.
2. Browse the products and add an item to the bag.
3. The bag stays saved after refresh because it uses browser storage.

## Simple folder guide

- `index.html` — home page
- `shop.html` — all blouse catalogues
- `product.html` — product details page
- `cart.html` — shopping bag and checkout
- `css/style.css` — all website styling
- `js/products.js` — product names, prices, colours and photos
- `js/main.js` — cart, filters and other website actions
- `images/` — product pictures, hero image and logo

## Editing products later

Open `js/products.js` in a text editor. Each blouse is stored in one clearly labelled product section, making it easy to update prices, ratings, colours, sizes and images.

## Deployment

This project uses plain HTML, CSS and JavaScript. It needs no build step and can be hosted directly with GitHub Pages or another static hosting service.
